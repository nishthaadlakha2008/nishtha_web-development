My Programming Notes

JavaScript

JavaScript is a programming language mainly used to make websites interactive. It can be used for buttons, forms, calculations and many other things on a web page. JavaScript is commonly used for web development.

Simple JavaScript example:


let name = "Nishtha";
console.log("Hello " + name);

Java

Java is a programming language used to create different types of applications. It is also used for software development and learning programming concepts. Java is known for being a widely used programming language.

Simple Java example:


public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

Python

Python is a simple and easy to learn programming language. It is used for web development, data analysis, artificial intelligence and many other tasks. Python is popular because its syntax is easy to understand.

Simple Python example:


name = "Nishtha"
print("Hello", name)

Quick Beginner Examples

JavaScript can print a message using console.log().

Java can print a message using System.out.println().

Python can print a message using print().
